# Cmax,u at the hepatic inlet

Cmax,u at the hepatic inlet

## Usage

``` r
imaxinletu(x, qh = 1.616, molar = TRUE)
```

## Arguments

- x:

  A perpetrator compound object.

- qh:

  Hepatic blood flow in l/min, defaults to 1.616 l/min.

- molar:

  Output in molar concentration (uM). Defaults to FALSE (ng/nl).

## Value

Numeric.
