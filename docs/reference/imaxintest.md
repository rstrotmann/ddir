# Intestinal Cmax,u

Intestinal Cmax,u

## Usage

``` r
imaxintest(x, qent = 18/60, molar = TRUE)
```

## Arguments

- x:

  A perpetrator compound object.

- qent:

  Enteric blood flow in l/min, defaults to 0.3 l/min = 18 l/h.

- molar:

  Output in molar concentration (uM). Defaults to FALSE (ng/nl).

## Value

Numeric.
